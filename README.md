# 검진결과관리

검진 결과를 관리하기 위한 개인 프로젝트입니다.

## 개발 환경

- C#
- .NET Framework 4.6.1
- DevExpress WinForms 20.2.6
- Microsoft SQL Server Express
- Stored Procedure 기반 데이터 접근

## 디렉터리 구성

- `src/`: C# 솔루션 및 프로젝트
- `database/`: 테이블 및 Stored Procedure 생성 스크립트
- `tests/`: 테스트 프로젝트(필요한 경우)

## 주의사항

데이터베이스 접속정보, 개인정보, 로컬 데이터베이스 파일 및 백업파일은 저장소에 포함하지 않습니다.
